# Self-hosted fonts

The site previously loaded these from Google Fonts. They are served locally now
so a visitor's IP is not sent to a third party on a page whose argument is
privacy.

- **Newsreader** — Copyright 2020 The Newsreader Project Authors.
- **Schibsted Grotesk** — Copyright 2022 The Schibsted Grotesk Project Authors.
- **IBM Plex Mono** — Copyright 2017 IBM Corporation.

All three are licensed under the SIL Open Font License, Version 1.1. The full
licence text is in `OFL.txt`. The files here are the `latin` and `latin-ext`
subsets from the Google Fonts repository; the CSS that maps them is
`src/fonts.css`.
